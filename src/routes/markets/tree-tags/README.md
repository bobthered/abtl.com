# Tree Tags

Route-owned market page using `ContentLayout` for the shared title, two alternating body sections, and centered closing contact invitation. Navigation adds Tree Tags after Fire Suppression; the Markets root continues to redirect to Fire Suppression.

The owner supplies the product scope: standard tag shape and custom die-cut tree shapes, available on any substrate, with Polyart and Tyvek most popular. Copy does not infer grades, dimensions, material performance, or certifications. The introduction contains the owner-provided substrate overview.

`TreeTagArtwork` uses the exact supplied `tag-shape.svg` and `tag-patch.svg` paths for standard tags. The custom profile and printed evergreen artwork are original concepts, including an extended stem and open fastening slot. Clip paths keep print inside the silhouettes and openings transparent. Reference images were inspected for format inspiration only; external images, branding, wording, and source URLs are not shipped. The illustrations do not define a production die or fastening specification.

Shared `FlipPreview` provides readable animated fronts and backs, a stationary bottom control, keyboard support, and reduced motion. Each artwork instance has an independent clip ID. Both dedicated shape previews remain fixed in size and flip independently.

The live farm name, tree type, and record number are client-local inputs with length limits. They update the artwork examples, are not submitted, and are not persisted. Empty inputs show illustrative placeholders. The first section presents only the standard tag and contains all personalization inputs. The second presents only the custom die-cut tree shape, sharing those personalized details. There are no shape or substrate selection controls. Future approved product SVGs can replace the artwork boundary without changing page controls.

Browser coverage checks exact standard geometry and patches, both shapes, front/back behavior, shared personalization, the two-section layout, first-section inputs, responsive layouts, both themes, keyboard flipping, no-JavaScript defaults, and navigation destinations.
