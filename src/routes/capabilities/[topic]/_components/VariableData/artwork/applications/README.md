# Application photography

Original illustrative product scenes generated with the built-in image_gen tool, using owner-supplied images as visual references only. Reference images are not shipped with the site. These scenes do not depict actual customer orders, and the codes in the photos are illustrative. Live encoded samples are provided separately in the interactive format comparison.

- `identification.webp`: inventory labels on kraft pouches.
- `personalization.webp`: a personalized hang tag on a knit garment.
- `scannable.webp`: an equipment label on a cable-mounted tag.

All three are 1200 x 900 WebP exports at quality 84. Exact generation prompts and export settings are recorded in `generation.json`.
